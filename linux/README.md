# YapYur Linux (Firefox) — Install

1. Extract the **YapYur Linux** folder.
2. Open **Firefox** (or LibreWolf / Waterfox).
3. Go to **about:debugging#/runtime/this-firefox**.
4. Click **Load Temporary Add-on…**
5. Select **manifest.json** from the extracted folder.
6. Open **yapper.website** or **yapin.gg** and **refresh**.

**Note:** Temporary add-ons are removed when Firefox closes. Reload the add-on the same way after a restart.
