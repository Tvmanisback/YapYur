# macOS downloads

Put the Mac build archive, disk image, or package in this folder. The website automatically links to the latest-named downloadable file in this folder.

Recommended filename: `YapYur-macOS.zip`

## Installation tutorial

1. Download and open the package.
2. Follow any README included with the build; the exact steps depend on whether it is an app archive, DMG, or package.
3. If macOS warns about an unverified developer, verify the download came from this official repository before deciding whether to proceed.

Add build-specific instructions here once the Mac package format is finalized.
