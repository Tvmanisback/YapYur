Install guides

Up and running in a few steps.

Follow the guide for your device. Only install files you trust and get them from the official YapYur repository.

 iPhone / iPad

  1. Install the “Userscripts” app from the App Store.
  2. iPhone Settings → Safari → Extensions → Userscripts → turn it ON (allow it for websites when asked).
  3. Open Safari.
  4. Open the YapYur userscript gist / raw link (the page that shows the .user.js script).
  5. Tap the Userscripts extension icon in Safari.
  6. Tap Install Userscript (or Install).
  7. Open https://yapper.website and refresh.
  8. Open Yapper’s gear → YapYur → Plugins / Themes.
Plugins are off by default — turn on only what you want. If Install doesn’t show, confirm Userscripts is enabled in Settings and you’re on the gist/raw script page in Safari.

▰ Windows

  1. Download the latest installer using the Windows button above.
  2. Open the downloaded .exe.
  3. Choose your Yapper install folder if prompted.
  4. Press Install and wait for the completion message.
  5. Open Yapper and find YapYur in its settings.
If Windows shows a security warning, only continue if you downloaded the installer from the official repository and trust the build.

⌘ macOS

  1. Download the Mac package above and open the downloaded archive or disk image.
  2. If it contains an app, move YapYur to Applications or follow the included README.
  3. If macOS blocks it, verify the file came from the official project before changing any security settings.
  4. Open the included instructions and follow any platform-specific install steps.
The exact steps depend on the format uploaded to mac/. Include a README with the build if it needs special setup.

⌁ Linux

  1. Download the Linux package above.
  2. Extract the archive if it is compressed.
  3. Open the included README and follow the steps for that package format.
  4. For an AppImage, make it executable in your file manager’s Properties → Permissions, then launch it.
  5. For a .deb package, install it with your distribution’s software installer if supported.
Package-specific commands should come from the README shipped with the build. Only run files from a source you trust.
Quick answers

Good to know.

What is YapYur?

YapYur is a community-made customization project for Yapper, with themes and optional plugins.

Where do platform downloads come from?

The site checks the android/, windows/, mac/, and linux/ folders in the official YapYur GitHub repository. Upload a build file there and the corresponding button will link to it.

Why does iOS use a userscript?

The iOS option opens the official YapYur userscript raw link. Install it using the Userscripts Safari extension and then refresh Yapper.

Are plugins enabled automatically?

No. Plugins are off by default, so you can enable only the ones you want from YapYur’s Plugins / Themes settings.
